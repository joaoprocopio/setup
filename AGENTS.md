## Language

Write everything in English: code, comments, docs, commits, issues, pull requests, and domain terms.

## Comments and docs

Answer your questions from the source code, and add docs only for what no line of code can say. Agents read docs and code alike as text, so time spent maintaining docs is wasted.

Write a comment, docstring or new Markdown file only when no code search answers the question. Keep a comment or docstring to one line, and put a longer why in an ADR under `docs/adr/`.

## Commits

Write every commit subject as a Conventional Commit, and put issue numbers in the pull request body.
